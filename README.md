## 💡 前端转 Agent 的“三大核心心法”

1. **以工程交付为本，绝不陷入算法死胡同**：
   - 算法岗解决的是“怎么训模型”，Agent 工程师解决的是“怎么用好模型解决具体业务”。
   - 你的核心武器是：**API 调度能力 + 状态机流转 + 复杂交互呈现（Generative UI） + 稳定性容错**。
2. **渐进式语言迁移**：
   - 前期（阶段一）直接用熟悉的 TypeScript + Vercel AI SDK 建立概念。
   - 中期（阶段二及之后）用 3~5 天掌握 Python + FastAPI，享受 Python 丰富的前沿 AI 开源生态。
3. **输出倒逼输入（Code First）**：
   - 每学完一个阶段，必须输出一个能在浏览器端点开运行的实战 Demo，拒绝只看不练。

## 📅 12周学习打卡追踪计划

- [ ] **Week 1-2：模型破冰** —— 跑通第一个 OpenAI / DeepSeek 流式打字机，掌握 JSON 结构化输出。
- [ ] **Week 3：Python速成** —— 熟练使用 `uv` 包管理，用 FastAPI 写出带 Pydantic 校验的微服务。
- [ ] **Week 4-5：原生 Agent** —— 不用任何库，纯原生手写一个能够调用“计算器 + 搜天气 + 查数据库”的 ReAct Agent。
- [ ] **Week 6-7：企业级 RAG** —— 搭建基于 PostgreSQL (pgvector) 的企业知识库检索服务，搞懂分块与 Rerank。
- [ ] **Week 8-9：复杂工作流** —— 掌握 LangGraph 状态图与 MCP 协议，完成支持“人工审批”的多智能体协作。
- [ ] **Week 10-12：毕业项目** —— 交付“企业级智能客服与工单自动化调度系统”，重构求职简历！
